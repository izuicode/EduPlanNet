Cómo Subir esta Web a Internet GRATIS con Tu Dominio

Paso 1: Alojar GRATIS en GitHub Pages ($0 USD)

  1. Crea una cuenta gratuita en GitHub.com.
  2. Crea un repositorio público llamado eduplan-uruguay.
  3. Sube este archivo guardándolo con el nombre exacto index.html.
  4. Ve a Settings -> Pages en tu repositorio y selecciona la rama main. ¡En 1 minuto tu web estará online!

Paso 2: Comprar Dominio con Mi Dinero

  1. Ingresa a Namecheap.com o NameSilo.com.
  2. Busca tu nombre deseado (Ej: mi-escuela.com). Cuestan entre $6 y $9 USD al año.
  3. Paga directamente con tu tarjeta internacional Mi Dinero / Prex / Oca Blue de Uruguay.
  4. En los ajustes DNS del dominio, vincúlalo a GitHub Pages indicando la URL de tu repositorio.
